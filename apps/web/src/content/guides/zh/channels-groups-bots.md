Telegram 里有三种容器，名字听起来像，用途完全不同：频道（channel）、群组（group）、机器人（bot）。选错了会很难受——用频道做讨论，或者用群组做公告，都会让你在几个月后不得不推倒重来。下面把区别一次讲清。

## 一句话概括

- **频道**：一对多的广播。只有管理员能发布，所有人只读，订阅人数**无上限**。
- **群组**：多对多的对话。所有成员（在权限允许下）都能发言，超级群组最多 **20 万人**。
- **机器人**：由第三方开发者用 Bot API 写的程序，跑在 Telegram 内部。它不是一个容器，而是一个参与者。

## 频道：广播

频道是为了把消息推送给大量受众而设计的。Telegram 官方的说法是频道"可以有无限数量的订阅者"。

它的几个关键特性：

- **署名是频道，不是你**。发布的消息带的是频道的名字和头像，而不是发布者本人的账号。对于多人共同运营的频道，这一点很重要。
- **每条消息有公开的阅读计数器**，而且转发副本的阅读量会计入原帖。
- **公开频道有用户名**，任何人都能在 Telegram 搜索里找到并加入；私密频道只能通过邀请链接进入。
- **所有者可以直接把最初的 200 个订阅者加进来**，超过之后就只能靠别人自己点加入了。这是一个常被忽略的启动额度。

频道不提供讨论区。如果你想让读者评论，正确的做法是**给频道关联一个讨论群组**：此后每条新帖都会自动转发到那个群里，评论发生在群里，频道本身保持干净。

## 群组：对话

群组分三种，差别主要在规模和功能。

**普通群组（basic group）**最多 **200 人**，功能相对少——没有公开用户名，没有细粒度的管理员权限。

**超级群组（supergroup）**最多 **20 万人**，是今天绝大多数社区实际使用的形态。它支持：

- 公开用户名和 `t.me/xxx` 链接；公开群组的**全部历史消息对新成员可见**，任何人都能加入并发言；
- 按成员逐项设置权限（能否发媒体、能否发链接、能否置顶……）；
- 给每个管理员单独配置权限，而不是"是或不是管理员"。

**广播群组（gigagroup）**是超级群组的一个变体：**取消了人数上限**，代价是只有管理员能发言。它适合"我需要一个成员列表可见、但实际上只广播"的场景。需要注意，从超级群组转成广播群组是**单向操作，不能撤销**，而且要由 Telegram 在合适的时候向管理员提示才能执行。

### 普通群组怎么变成超级群组

这是最常被问到的问题，而答案是：**你通常不需要手动做任何事**。

Telegram 的客户端规范写得很直接：当管理员尝试执行一项只有超级群组才支持的操作时，客户端应当自动把普通群组迁移为超级群组。给群设置一个公开链接、或者人数超过 200，都会触发这个迁移。

迁移发生时，旧群里所有人会收到一条服务消息，指向新的超级群组，之后的新消息都发到新群里。实践中你会看到聊天列表里那条熟悉的"群组已升级为超级群组"提示。客户端界面里没有反向操作，所以把它当作一次性的改变来规划。

## 机器人：跑在 Telegram 里的程序

机器人不是第三种聊天室，而是一类特殊账号，由外部开发者通过 **Bot API** 实现。你可以把它理解成一个只会按程序回应的参与者。

关于机器人，有几件事值得知道：

- **机器人不能主动找你**。必须你先启动它，或者把它加进群里。任何"机器人主动私信你"的情况，都值得怀疑。
- **它可以被加进群组或频道当管理员**，用来做反垃圾、欢迎语、投票、自动发布。
- **它看不到群里的一切**——除非被设为管理员或关闭了隐私模式，否则它只能收到命令和提到它的消息。
- 机器人是**第三方写的**。它能看到你主动发给它的内容，所以不要把敏感信息交给一个来路不明的机器人。

本站的收录流程本身就是一个机器人：你把频道链接发给它，它去抓公开资料，审核结果再私信回你。

## 该用哪一个

| 你想做的事 | 选择 |
|---|---|
| 发布公告、更新、资讯，不需要读者发言 | 频道 |
| 发布内容，但希望有评论区 | 频道 + 关联讨论群 |
| 让一群人互相交流、互助答疑 | 超级群组 |
| 规模极大但只需要广播、又想保留成员列表 | 广播群组 |
| 自动化：审核、欢迎、查询、定时发布 | 机器人（加进频道或群里） |
| 提供一个查询/工具类服务 | 独立的机器人 |

几条经验：

- **不确定就先建频道**。频道可以随时关联一个讨论群把对话打开；反过来，把一个已经吵了半年的群变成安静的公告渠道要难得多。
- **超过一两百人的群必须配管理规则**。超级群组的权限是逐项的，先关掉新成员发链接和转发，比出事之后再补要省力。
- **公开就是真的公开**。公开群组的历史消息对任何路过的人可见，公开频道有网页预览页。要私密就别设用户名。

## 这对找频道意味着什么

作为读者，弄清这三者的区别能省很多时间：如果你要的是"每天被动接收某个主题的信息"，你要找的是**频道**；如果你要的是"提问有人回答"，你要找的是**群组**；如果你要的是"帮我算一下汇率/下载一个文件"，你要找的是**机器人**。
